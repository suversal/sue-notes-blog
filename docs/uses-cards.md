## 手机卡保号

- giffgaff 人在国内的漫游短信，公开价目里没有中国区单条价格，没有套用别的国家的例子。
- 乌龟电信连上基站可以是 0 欧元。一年完全不连才会从余额扣一笔，金额没写死。
